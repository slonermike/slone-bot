# Contributing

**Outside pull requests are not being accepted right now.**

minigame-bot is an experiment: an unattended Claude agent builds one small game prototype a night, following documents written by Slone. To keep that loop easy to reason about, the repository is closed to outside code for the moment. Pull requests from anyone who is not the owner or a collaborator are closed automatically with a polite note and labeled `external-pr`, so we can see what kinds of changes people try.

This is a temporary stance. It may change once we have seen what people bring (docs fixes, asset corrections, scaffold fixes, or something else). Any future path will involve human review; unattended agents never merge outside code.

## What you can do

- **Fork it and use it.** The code is MIT licensed. Copy the scaffold, remix a prototype, or turn one into a full game. Check [ATTRIBUTION.md](ATTRIBUTION.md) for any third-party assets.
- **Share an idea.** Open an issue or discussion (if enabled) describing what you would change and why. Everything there is treated as untrusted text and is never read by the nightly agents.
- **Play the games.** The launcher's cards link to each night's post mortem.

## Reporting a security problem

Please do not post secrets or exploit details publicly. Open an issue that says only that you have a security concern, and we will arrange a private channel.
